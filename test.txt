词汇表

| 术语 | 解释 |
|------|------|
| JVM (Java Virtual Machine) | Java 虚拟机，负责运行编译后的字节码，实现跨平台 |
| 字节码 (Bytecode) | Java 源码编译后的中间产物，由 JVM 执行 |
| 静态类型 (Static Typing) | 变量类型在编译时确定，不可随意改变 |
| 动态类型 (Dynamic Typing) | 变量类型在运行时确定，Python 采用此方式 |

| 强制转型 (Casting) | 手动将一种类型转换为另一种，如 `(double) a` |
| 增强 for 循环 (Enhanced for) | `for (int n : nums)` 语法，类似 Python 的 `for x in list` |

---

Java 与 Python 核心区别

Python 是多范式语言（面向对象 + 函数式 + 过程式），非常灵活。
Java 是强制面向对象语言，所有代码必须在类中，类型系统严格，适合大型系统和团队协作。

关于"类多是否臃肿"：
Java 的多类设计是优点，不是缺点。每个类职责单一，结构清晰，便于团队分工和维护。
类比：Python 像个人工作室，Java 像大公司仓库——规模越大，结构化的优势越明显。

Java 程序基本结构

每个 Java 程序都需要一个类和一个 main 方法作为入口：

```java
public class Main {
    public static void main(String[] args) {
        System.out.println("Hello, World!");
    }
}
```

对比 Python：
```python
print("Hello, World!")
```

记住这个骨架，每次写 Java 都从这里开始。

基本数据类型

| Java 类型 | 说明 | Python 对应 |
|-----------|------|------------|
| `int` | 32位整数 | `int` |
| `long` | 64位整数，末尾加 L | `int` |
| `double` | 64位浮点数 | `float` |
| `boolean` | 真/假 | `bool` |
| `char` | 单个字符，用单引号 | 无（Python 用 str） |
| `String` | 字符串，注意大写 S，用双引号 | `str` |

```java
int age = 20;
long bigNum = 10000000000L;   // 末尾必须加 L
double pi = 3.14;
boolean flag = true;
char letter = 'A';            // 单引号
String name = "Alice";        // 双引号
```

注意：char 用单引号，String 用双引号，不能混用。写 `char c = "A"` 会编译报错。

变量声明规则：
- Java 必须先声明类型再使用
- 一旦声明，类型不可改变

```java
int x = 5;
x = 10;       // 合法
x = "hello";  // 编译报错！
```

| 操作 | Python | Java |
|------|--------|------|

整除陷阱：
```java
int a = 7, b = 2;
System.out.println(a / b);           // 输出 3，不是 3.5！
System.out.println((double) a / b);  // 输出 3.5，需要强制转型
```

控制流

if / else：
```java
if (x > 0) {
    System.out.println("正数");
} else if (x == 0) {
    System.out.println("零");
} else {
    System.out.println("负数");
}
```
注意：条件必须加圆括号，代码块用大括号划定（不靠缩进）。

for 循环（三段式）：
```java
for (int i = 0; i < 5; i++) {
    System.out.println(i);
}
```
结构：(初始化; 条件; 每轮结束后执行)

增强 for 循环（遍历数组）：
```java
int[] nums = {1, 2, 3, 4, 5};
for (int n : nums) {
    System.out.println(n);
}
```

while 循环：
```java
int i = 0;
while (i < 5) {
    System.out.println(i);
    i++;
}
```

---

常见语法细节（从 Python 转 Java 易错点）

1. 每条语句结尾必须加分号 `;`
2. 条件判断必须加圆括号 `if (x > 0)`
3. 代码块用大括号 `{}` 而非缩进
4. 打印变量用 `System.out.println(i)`，不要加引号，否则打印的是字符串 "i"
5. for 循环三段之间用分号 `;` 分隔，不是逗号

课堂练习：打印 1 到 100 中能被 3 整除的数

错误版本（记录学习过程）：
```java
for (int i = 0; i < 101, i ++) {  // 逗号应为分号
    if (x % 3 == 0) {              // x 未定义，应为 i
        System.out.println("x")    // "x" 是字符串，应为变量 i；缺分号
    }
}
```

正确版本：
```java
for (int i = 1; i <= 100; i++) {
    if (i % 3 == 0) {
        System.out.println(i);
    }
}
```
